# Prompts
Here are some useful prompts.

## list all artifacts
*Use `#artifactCategories` to list every available artifact category, then use `#artifactArtifactsFromCategory` for each category to list all artifacts. Return the complete category-and-artifact inventory, grouped by category, without omitting any entries.`*

## place an artifact
*Use `#artifactCategories`, `#artifactArtifactsFromCategory`, and `#artifactArtifactSnippet` to build a Contact Form from library snippets only. Include a container, first name, last name, email, phone, company, subject, message, and a submit button at the bottom.*

## remove an artifact
*Use `#artifactCategories`, `#artifactArtifactsFromCategory`, and `#artifactArtifactSnippet` to identify the CTA Banner and remove just that artifact from the document. Preserve the rest of the document.*
